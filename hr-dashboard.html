HR Analytics Dashboard

Five-page Power BI report built from messy HR data, covering headcount, pay, performance and attrition

September 9, 2026 Angela Iseriehen

The goal

To practise the full business intelligence workflow on a realistic problem, starting from a deliberately messy HR dataset and ending with an interactive report that answers questions about headcount, pay, performance and attrition.

Cleaning the data in Power Query

  • Removed duplicate records and trimmed stray whitespace
  • Standardised inconsistent department names
  • Parsed dates written in several formats using a reusable custom M function
  • Handled missing values case by case, depending on what each field meant
  • Corrected salary anomalies
  • Added calculated columns for age, tenure, employment status, age band and tenure band

Modelling and DAX

I built a calendar table marked as the date table, with an active relationship to hire date and an inactive one to termination date, which I switched on in DAX with USERELATIONSHIP. The measures cover headcount (total, active and terminated), attrition rate, average and median salary, average tenure, performance rating, engagement score, hires and terminations.

The dashboard

A five-page interactive report with a persistent sidebar for navigation: Overview, Demographics, Compensation, Performance and Engagement, and Attrition Analysis. It uses a custom theme file, and I wrote a separate data quality document to record every cleaning decision.

Headline numbers

The overview page shows 180 employees, an average salary of $79K, an average tenure of 6.5 years and an attrition rate of 15.0%.
