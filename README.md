# Angela Iseriehen | Data Analyst Portfolio

A personal portfolio website showcasing my data analytics projects in Power BI, Excel and Python.

**Live site:** https://angela-825.github.io

## Projects
- **HR Analytics Dashboard:** five-page Power BI report built from messy HR data
- **Logistics Operations Capstone:** four-dashboard Power BI analysis of a 14-table logistics database
- **Superstore Sales and Profit Dashboard:** three-page Power BI report on discounts and profitability
- **HealthConnect Clinic No-Show Analysis:** Python analysis of 5,000 clinic appointments
- **Excel Sales Analysis Dashboard:** interactive Excel dashboard
